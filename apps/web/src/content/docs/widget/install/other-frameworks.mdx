---
title: Other Frameworks
description: Install the Faster Fixes widget on Astro, Solid, Preact or any other stack.
---

Every framework without its own embed uses the widget directly, from the [script embed](/docs/widget/install/script-embed) or from the `@fasterfixes/widget` package. The widget, its options and its [control contract](/docs/widget/control-the-widget) are the same on every stack. Get your Project ID in [Project Settings](https://faster-fixes.com/settings).

## Astro

Add the script tag to the layout shared by every page. `is:inline` tells Astro to leave the tag as written instead of bundling it.

```astro title="src/layouts/Layout.astro"
<html lang="en">
  <head>
    <script
      is:inline
      src="https://cdn.jsdelivr.net/npm/@fasterfixes/widget@1/dist/widget.iife.js"
      data-project-id="proj_your_project_id"
      defer
    ></script>
  </head>
  <body>
    <slot />
  </body>
</html>
```

The tag accepts the same `data-*` attributes as the [script embed](/docs/widget/install/script-embed#attributes).

## Solid

Install the widget package:

```package-install
@fasterfixes/widget
```

Call `init` in `onMount` of the root component and destroy the widget in `onCleanup`. `onMount` only runs in the browser, so this also works with SolidStart server rendering.

```tsx title="src/App.tsx"
import { init } from "@fasterfixes/widget";
import { onCleanup, onMount } from "solid-js";

export function App() {
  onMount(() => {
    const widget = init({ projectId: "proj_your_project_id" });
    onCleanup(() => widget.destroy());
  });

  return <main>{/* your app */}</main>;
}
```

`init` accepts the [option object](/docs/widget/install/script-embed#option-object) and returns the widget [instance](/docs/widget/control-the-widget).

## Preact

Preact 10 runs the [React embed](/docs/widget/install/react) through `preact/compat`. Install the React package:

```package-install
@fasterfixes/react
```

With Vite, `@preact/preset-vite` already aliases `react`, `react-dom` and `react/jsx-runtime` to `preact/compat`. With another bundler, add the same aliases. Then use `FeedbackProvider` and `useFeedback` as documented on the React page:

```tsx title="src/main.tsx"
import { FeedbackProvider } from "@fasterfixes/react";
import { render } from "preact";
import { App } from "./app";

render(
  <FeedbackProvider projectId="proj_your_project_id">
    <App />
  </FeedbackProvider>,
  document.getElementById("app")!,
);
```

## Vanilla and any other stack

With a bundler, install `@fasterfixes/widget` and call `init` once, in the entry file that runs on every page:

```ts title="src/main.ts"
import { init } from "@fasterfixes/widget";

const widget = init({ projectId: "proj_your_project_id" });
```

Call `widget.destroy()` if your app tears down its page without a full reload. Without a bundler, or on a CMS, use the [script embed](/docs/widget/install/script-embed) tag.
