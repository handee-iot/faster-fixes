## 2. Get your Project ID

Go to [faster-fixes.com](https://faster-fixes.com), create a project, and copy the Project ID from project settings. Use it wherever the install page asks for your Project ID.

## 3. Collect your first feedback

To test the widget yourself:

- In your project dashboard, go to **Reviewers** and create a reviewer (e.g. "Client - John"). Copy the review link.
- Open your site using that link. A floating button appears. Click it, then click any element on the page to annotate it. Write a comment and submit.
- Go back to your project's **Inbox**. The feedback appears with the screenshot, page URL, browser info, DOM selector, and a diagnostics view with the console logs and network requests captured before submission.

In practice, share the review link with your actual clients so they can leave feedback directly. See [Reviewer Tokens](/docs/concepts/reviewer-tokens) for more on managing reviewers and access.

## 4. Connect your AI coding agent

Create an agent token in [Integrations](https://faster-fixes.com/integrations). Then add `.mcp.json` to your project root:

```json title=".mcp.json"
{
  "mcpServers": {
    "faster-fixes": {
      "command": "npx",
      "args": ["-y", "@fasterfixes/mcp"],
      "env": {
        "FASTER_FIXES_TOKEN": "ff_agent_xxx",
        "FASTER_FIXES_PROJECT": "proj_xxx"
      }
    }
  }
}
```

See the [MCP setup guide](/docs/mcp/setup) for other editors (Cursor, VS Code, Windsurf, Codex, Zed).
